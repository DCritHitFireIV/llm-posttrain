# 实验报告：S-GRPO（arXiv 2504.20834）on multistep

> 完成时间：2026-09-14｜实验协议（先于训练冻结）：`docs/prereg.md`
> 验收结论：**预注册双门通过（正结果）**——McNemar 精确 p=2.23×10⁻¹³⁹ ∧ bootstrap 95% CI 下界 +32.7pp > 0。

---

## 1. 结论（一句话）
在程序化生成的 5–6 步应用题族 **multistep**（四类模板）上，用 **S-GRPO**（4bit QLoRA、batch=1、G=8、token 子采样）对 GSM8K-SFT 模型做 450 步 RL，**test n=2000 一次性终评：53.05% → 88.25%（+35.2pp）**，discordant=894（RL-only 799 / SFT-only 95）。增益高度集中在 SFT 原本几乎失败的模板（水池 3.6%→88.2%、储蓄 27.8%→90.4%），最易模板（仓库 93.0%→86.6%）轻微回退。

## 2. 背景：任务难度的作用
- 对可验证任务做 RL，训练信号由**题目难度**决定：组内 G=8 个答案全对或全错时组内优势恒为 0，该步不产生有效梯度。
- 因此任务按“SFT 起点准确率落在 20–60% 可学习区间”构造：程序化生成的 5–6 步文字应用题，四类模板轮换，答案整数、程序化 verifier 精确匹配。
- 训练前的温度探针（§3）确认该区间可用：temp=1.0 档组内 mixed=100%、全错组 0%。

## 3. 实验协议（冻结要点，全文见 docs/prereg.md）
- 任务：multistep（仓库/水池/储蓄/机器 四模板轮换；答案整数、程序化 verifier 精确匹配）。
- 划分：train=2000（seed 3001）/ val=240（seed 3002，仅 ckpt 选择）/ **test=2000（seed 3003，一次性）**；题面 sha256 交集=0。
- 模型：`models/Qwen3-1.7B-Base`（4bit NF4）+ `outputs/sft_lora`（policy 可训副本 / ref 冻结）。
- 方法（S-GRPO）：G=8，组内标准化 advantage；token 入选 t<50 恒选、t≥50 且计数<100 时 Bernoulli(0.5)；μ=1 无 clip、ref 不更新；β_KL=0.01（k3）；LoRA q,v 仅最后 1/3 层 r16/α32；AdamW lr=1e-4、wd=0.01；450 步；温度由预注册规则在 train-only 探针上冻结为 **1.0**（0.3 档 mixed=45.8%/all_wrong=16.7%；1.0 档 mixed=100%/all_wrong=0%）。
- 成功线：test 配对 Δ 的 McNemar 精确 p<0.05 **且** bootstrap（10k, seed 20260914）95% CI 下界>0。

## 4. 训练动态（450 步，共 233.3 min，均 29.4s/步）
- 有信号步（组内非全同）142/450 = **31.6%**；zero-advantage 步 308/450 = 68.4%。
- 训练 reward：前 50 步 0.765 → 中段 0.945 → 末 50 步 0.932（第 ~200 步起饱和，与 val 峰值一致）。
- S-GRPO 入选 token 占比 0.629（原论文报 30–50%，其 completion 更长；本任务 completion ~150 token，α=50+至多 50 采样 ≈ 2/3）。
- KL 均值 0.170；显存峰值 2.98 GB；ckpt 每 50 步（9 个）。

## 6. test 终评（n=2000，HF 4bit 贪心，两臂同 session 按 batch 交替；一次）
| 指标 | SFT | RL |
|---|---|---|
| 正确数 | 1061/2000 | 1765/2000 |
| acc | 0.5305 | 0.8825 |

- Δ = **+35.2pp**；discordant = 894（RL-only 799 / SFT-only 95）；both_correct 966；both_wrong 140。
- McNemar 精确双侧 **p = 2.23×10⁻¹³⁹**；bootstrap 95% CI = **[+32.7, +37.8]pp**；MDE(80% power, 观测 discordance) ≈ 4.19pp。
- 分区间一致性（500 题/段）：Δ = +35.6 / +36.0 / +33.8 / +35.4 pp（含崩溃点 1552 前后，无断点）。
- 按模板拆解：
  | 模板 | SFT | RL | Δ |
  |---|---|---|---|
  | 0 仓库箱数 | 0.930 | 0.866 | −6.4pp |
  | 1 水池排水/注水 | 0.036 | 0.882 | **+84.6pp** |
  | 2 储蓄/花费 | 0.278 | 0.904 | **+62.6pp** |
  | 3 机器零件 | 0.878 | 0.878 | 0 |
- 完整性抽查：两臂 ~99% 输出含 `####`，无 >1000 字符文本（无截断假象）；两臂 ID 逐一对齐、2000 题无重复。

## 7. 解读与局限（引用前必读）
1. **增益是"学结构/格式"型**：集中在 SFT 不懂的水池/储蓄两类模板（SFT 近乎全错），RL 学会分步格式与结算顺序后拿到 ~90%；对已会的模板 0 有 −6.4pp 回退、模板 3 持平。
2. **同分布泛化**：test 是同一 generator、不同 seed 的新数字；结论不能外推到其他任务族（如 GSM8K）。
3. **口径**：绝对值是 HF 4bit 贪心；两臂同后端同 session，配对 Δ 有效；跨后端引用需谨慎。
4. **饱和**：训练后段 68% 步无梯度（组内全同），第 200 步后 val 回落——方法收益在早期；这本身是 「选择性 token 更新」的适用边界证据。
5. **执行说明**：S2 温度探针耗时 15.7 min（超出预估，不影响口径）；终评 batch 曾 8→16→8（回退，未生效）；S4 终评在 1552/2000 处遇 CUDA 错误后**确定性续跑**（不重跑已完成题、不重选 checkpoint）。
